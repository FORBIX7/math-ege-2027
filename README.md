# Математика — учебник и практика, версия 2.1

Авторский автономный учебный сайт для подготовки к базовому ЕГЭ по математике. Основной интерфейс рассчитан на телефон. Статическая сборка не требует аккаунта, серверной базы, ключей API или установки зависимостей.

## Что реализовано

- 45 тем; к исходным объяснениям добавлены 123 смысловые главы (245 абзацев). В каждой теме доступны содержание, сохранение главы, основные правила, углублённое объяснение, модель, разборы и повторение.
- 40 управляемых моделей: числа, дроби, проценты, разряды, степени, корни, логарифмы, системы, парабола, разрывы, неравенства, функции, тригонометрия, производная, интеграл, статистика, вероятность, множества, тарифы, движение, работа, смеси, последовательности, планиметрия, координаты, тела и вытеснение воды.
- Графики имеют шкалы и подписи. Производная содержит секущую, касательную и отдельный график производной; сравниваются квадрат и модуль. В тригонометрии связаны окружность и графики синуса/косинуса.
- Из текущих параметров каждой модели формируется связанное упражнение. Оно учитывается как работа с моделью, поскольку значение могло быть уже показано. Для независимого контроля используются новые задания.
- 315 исходных упражнений, 45 смысловых контрольных вопросов и 90 параметрических семейств новых заданий (по два на тему). Идентификатор содержит версию генератора и seed; история сохраняет снимок условия и решения.
- В каждой теме есть наглядное объяснение внутри смысловой главы: схема, рисунок или управляемая модель. Урок начинается со смысла, затем переходит к правилам. В действиях с дробями и обратном проценте объяснение может подставлять данные текущего задания; возврат сохраняет введённый ответ.
- После неверного ответа можно исправиться: решение не раскрывается автоматически. Есть 90 указаний к конкретным семействам, выбор причины ошибки и новая похожая задача с другим условием. Решение сразу после помощи отмечается как закрепление с поддержкой.
- Тематическая, смешанная, короткая и отложенная практика; ступенчатые подсказки; разбор ошибок с указанием причины; самостоятельное повторение.
- Карта зависимостей показывает основы, выбранную тему и последующие применения. Статус имеет объяснимые условия, а неизвестная тема не объявляется проваленной.
- Краткая диагностика основ и проверки разделов с вопросами на понятия и новыми задачами.
- Авторские тренировочные работы из 21 позиции, 180 минут, сохранение ответов и незавершённой работы, переход между заданиями, проверка после сдачи и отчёт последних пяти работ. Это ограниченная подготовительная модель, не официальный КИМ и не гарантия оценки.
- Поиск тем и формул, избранное, печать темы целиком и подборок с отдельным разделом решений.
- Локальный конструктор своих задач; задачи входят в резервную копию.
- Сжатый код прогресса, QR для подходящего объёма, JSON; предпросмотр, замена или объединение с удалением дублей. Перед восстановлением скачивается текущая резервная копия. Старый формат первой версии поддерживается.
- Настройка размера текста, отключаемые переходы и поддерживающие сообщения. Системное уменьшение движения учитывается. Звук и декоративные игровые награды не используются.
- Автономная загрузка через Service Worker с видимым статусом подготовки к работе без сети; манифест установки и иконки для домашнего экрана.

## Запуск и GitHub Pages

1. Распакуйте архив. В корне должны лежать index.html, data.js, course.js, concepts.js, hints.js, engine.js, visuals.js, panels.js, app-v2.js, style-v2.css и папка vendor.
2. Для простого просмотра на компьютере откройте index.html. Установка и автономный кэш требуют HTTP localhost или HTTPS.
3. Локальный сервер пользователю не нужен: после публикации все ресурсы загружаются с GitHub Pages. На iPhone достаточно ссылки.
4. Для GitHub Pages загрузите содержимое папки в репозиторий, затем Settings → Pages → Deploy from a branch → нужная ветка → корень. Файл .nojekyll также включён. Пути относительные, поэтому подпапка репозитория поддерживается.
5. Откройте выданный GitHub HTTPS-адрес. На iPhone в Safari используйте «Поделиться → На экран Домой».
6. До поездки загрузите сайт, дождитесь внизу страницы сообщения «Материалы сохранены для работы без сети» и проверьте повторное открытие без интернета. Первая загрузка без сети невозможна.

Репозиторий: https://github.com/FORBIX7/math-ege-2027 . Публикация настроена из ветки `main`, корень `/`. Следующие изменения отправляются командой `git push origin main`; GitHub Pages обновляет сайт после сборки.

## Как читать статус темы

Для «закреплено» в этой версии нужны:

- самостоятельный ответ на смысловой вопрос;
- 7 исходных упражнений темы без самопроверки;
- не менее 8 разных условий новых задач по двум доступным семействам;
- успешная самостоятельная практика в 3 разные даты, включая отложенную встречу спустя сутки;
- достаточный объём последних самостоятельных попыток и успешность не ниже 87,5%.

Это рабочие критерии именно по доступным упражнениям. Они не доказывают освоение всех возможных формулировок ЕГЭ и не являются вероятностью получения оценки. Просмотр текста, движение ползунков, раскрытие решения и самопроверка не закрывают самостоятельный контроль. Прежние попытки сохраняются как история, но не присваивают новый статус автоматически.

## Проверка ответов и границы

Числа и рациональные дроби сравниваются точно через целочисленную арифметику. Поддерживаются десятичная запятая и точка, минус, ряд смешанных дробей, наборы простых числовых корней. В заданиях «приведите пример» проверяются условия, а не совпадение с единственным образцом.

В самостоятельной работе требуется числовой формат ответа по инструкции; учебная дробь не подменяет конечную десятичную запись. Генератор работы подбирает ответы, допускающие конечную запись.

Для сложных открытых форм исходных упражнений допускается явно обозначенная самопроверка. Эквивалентность произвольных буквенных выражений, рукописные рассуждения и доказательства автоматически не устанавливаются. Подстановка пользовательского текста в eval не используется. У задач конструктора правильность введённого автором условия и доказательства требует авторской проверки.

Семейства генераторов ограничены. Некоторые проверяют основу навыка; весь спектр экзаменационных задач ими не исчерпан. Для завершения подготовки необходимо решать официальную демоверсию и задачи открытого банка соответствующего года. Курс базовый; подготовка на 100 баллов профильного ЕГЭ не заявляется.

## Данные

Вся история хранится в браузере. Очистка данных сайта может её удалить. Ёмкость хранения ограничивается браузером: при ошибке сохранения приложение сообщает о необходимости резервной копии. Автоматической облачной синхронизации нет.

Код переноса сжат, снабжён контрольной суммой от случайной порчи и НЕ зашифрован. Не помещайте в свои задачи личные или секретные данные. На HTTPS QR содержит ссылку с данными во фрагменте URL и открывает предпросмотр; автоматической замены прогресса нет. Для длинной истории используется файл или полный код, история ради QR не обрезается.

При обновлении можно сохранить работу, закрыть вкладки и открыть сайт снова. Исходники обновляются через сеть, а при отсутствии сети используются загруженные ресурсы. Шрифты и библиотеки поставляются локально; внешней аналитики нет.

## Проверки поставки

Выполнены автоматические проверки 9000 генераций, воспроизводимости, приёма правильного ответа, запрещённого деления, точного сравнения дробей, конечного формата ответов в 100 работах и проверки допустимых примеров. Для отдельных моделей использованы независимые проверки подстановкой и перечислением исходов. Проверены 136 состояний визуализаций, связанные упражнения и рендеринг формул.

В настольном браузере проверены узкая ширина 390 пикселей, практика, восстановление после перезагрузки, завершение работы, другой допустимый ответ задачи на цифры, контроль понятия и учёт работы с моделью как помощи. Такая проверка не заменяет испытание на физическом iPhone в Safari, с камерой, меню «Файлы» и VoiceOver. Дополнительная предметная редактура перед широким учебным использованием остаётся необходимой.

## Обновления с компьютера

Исходники сайта находятся в этой папке. Рабочая ветка — `main`. После изменений:

```sh
node tests/smoke.cjs
git status
git add .
git commit -m "Describe the site update"
git push origin main
```

При включённом GitHub Pages из `main` и корня репозитория новый push запускает публикацию. Локальный сервер для пользователей не требуется. Файлы прогресса учащихся в репозиторий не добавляются: они остаются в браузере или личной резервной копии.
